# Q4 抽取设计

我先检查原文而非按低评分猜问题：空白保留无证据状态，严格白名单的好坏短语只给情感，其他交给葡语模型。每行保留来源行、订单和评价标识，防止重复评价 ID 被覆盖。模型直接理解葡语，只翻译引用片段，减少翻译费用与语义传递错误。

我选择小批同步 JSON 请求以便在四十分钟内定位失败。批量共享提示，但输出易截断，因此先试四条；不把异步批处理折扣当作已获得。程序核对字段、枚举、数值和逐字引文；否定关系、翻译与归责仍需人审，格式正确不等于事实正确。

计费先按已核实的上下文与输出上界预留，响应后用真实 usage 结算；超时保留预留，不自动重试。共用账本锁和行级缓存，扩大样本时不重复收费。三美元上限依赖配置报价正确，还须与账单核对。

我把非空低分原文固定抽三十条，先盲标类别再解盲检查翻译及严重度，报告分母和逐条差异。目前服务和真人标签未到位，只验收工程闭环，不填造准确率。规则置信度是启发值，无文本零分表示未知，并非已证中性；未来可用标注修订分流。
