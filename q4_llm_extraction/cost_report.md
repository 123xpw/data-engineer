## 单条与批量的同口径对照

实际已采用批处理及有界修复，累计usage见上方；未进行全量单条实测，因此不能给出实际单条总价或声称测得节省比例。批处理是一次请求容纳多条，不等于已获得异步Batch折扣。

令N为评论数、B为批大小、P为每次固定提示token、T为评论文本输入token总量、H为每批额外包装token；I/O为输入/输出USD每百万token，O1/OB为两策略输出token总量，R1/RB为修复额外USD。相同文本T是对照假设，实际分词/包装可能变化。

```text
C_single = (I * (N*P + T) + O * O1) / 1000000 + R1
C_batch  = (I * (ceil(N/B)*(P+H) + T) + O * OB) / 1000000 + RB
```

共享提示的节省必须抵消包装、输出差异、截断与修复费用；批量可能更贵，不能默认两种策略质量相同。累计真实费用已含修复，公式R仅用于明确假设的情景，不再加到真实累计值上。
