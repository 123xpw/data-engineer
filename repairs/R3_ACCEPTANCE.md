# R3：当前运行与产物归属

实施前标准：总入口及 Q1.1/Q1.2/Q1.3/Q2.1/Q2.2 独立 CLI 产生唯一运行编号。每题在空暂存目录完整生成约定文件后才能发布成功清单，清单记录输入声明、源码指纹、文件哈希和数据库批次。新运行开始即替换旧成功状态；失败不得登记旧文件为本轮产物。

必须实测：先成功，再缺输入失败；旧文件保留但新清单拒绝读取。伪成功不写文件、只写部分文件、文件篡改、错误编号、源码变化均拒绝。Q2.1 故障不阻止独立 Q2.2。真实 CLI 与独立参考复算保持一致。验收不能只依赖测试个数。

边界：该协议约束正式 CLI。内部计算函数保留供独立参考和故障实验使用，不自动登记为交付。不承诺并发发布隔离、跨文件系统事务或恶意者同时重写文件及清单时的防伪；强杀时 running 状态也应拒绝。文件存在本身不再是成功条件。
