# 修复 R1：验收不能在断言被禁用时报告通过

实施前标准：普通 Python 的正确 SQL 应通过；审查中同一“漏运费”变体必须失败。-O、-OO、PYTHONOPTIMIZE=1/2 必须在任何验收动作前明确失败，写出新的失败状态覆盖 latest 的旧成功指向，保留历史文件；不得执行数据库、下载或业务检查后再假装验收有效。

关键比较使用显式条件异常，错误捕获结果来自实际差异；至少保存合成反例的差异字段，不能无条件写 True。测试端用子进程和真实 MySQL 临时表重放，不以 mock 替代缺运费 SQL 的检测。完整已有回归应通过。

本轮贡献：防止运行模式关闭断言后产生虚假验收证据。限制：不能自动证明业务语义、修复数据库配置、消除旧产物歧义，也不补齐未实现模块。本轮不改变生产 SQL 和业务数据。
