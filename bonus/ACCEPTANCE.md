# 加分题本轮验收标准（写作前）

Q6.1 必须指向原始可见对话，首个相关用户 prompt 与 AI 回答原样引用，不将后来改写的提示伪装成当时原文。明确用户轮次、助手更新与代码提交不是同一计数；每个关键失败都指向已有源代码/报告或 Git 历史。AI 协助分析不得冒称本人已经独立发现或理解。未修复局限明确保留。

Q6.2 正文 300..600 非空白字符，每个建议包括现象、可执行动作和收益/成本假设。数值需由冻结 CSV/Decimal 或独立参考重算；已观察金额差与假设收益分开，不把历史取消候选当确认退款，不把数据修正当新增收入，不引用模板中虚构的提升率。

程序核查字数、原文片段/轮次和事实数值的一致性；文本业务可行性仍是同一 AI 的分析，不能代替业务方确认或独立评审。
