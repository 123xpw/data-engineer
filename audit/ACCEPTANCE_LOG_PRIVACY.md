# 本轮日志隐私标准

候选人最新选择：只交付脱敏材料，不提供含个人信息的原文附件。当前已有日志脱敏仅针对账户段落，本轮扩展到已知姓名、账号、本地用户路径、联系方式。不得把脱敏日志称为完整未删改原文，也不擅自声明面试方已经接受例外。

1. 不改本地私有原文；公开副本中的敏感段落用明确占位符替换，记录消息/块/段落位置，其余文字、角色、时间、轮次保持一致。
2. 当前公开日志检查指定姓名、账号、本地用户名、邮箱/手机号模式无命中；检查真实已知敏感值的阳性控制。此范围不等于所有未知个人信息识别保证。
3. 用逐段对照验证未遮盖部分原样保留；加分题原文引用若受影响，实际运行其验证，不能改引文来配合通过。
4. 检查现有公开版本和本地候选的可达历史，分别报告当前文件与历史。现已确认旧公开提交含姓名及本地用户路径；普通新提交不能移除这些历史。未经候选人明确选择，不推送新版本，不强推，不删除历史。
5. 隐私例外、真人评估缺项与原文要求如实列入交付说明；从代码包排除未脱敏原文和私有配置/账本。当前文件检查通过不代表全部历史隐私问题已经关闭。
