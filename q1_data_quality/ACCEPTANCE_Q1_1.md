# Q1.1 开始前确定的范围与验收标准

## 范围与口径

本轮只做质量初探，不清洗原始数据、不解释退货原单、不实现 SQL/ETL。
数据来源固定为 Online Retail II 第 3 版，原始字段和字节不变。

- 全部 8 列先按原始字符串读取，保留 ID 前导零、Customer ID 的 .0 后缀及描述两端空白。
- 缺失仅指 CSV 解码后的空字符串。纯空白字符串另计，不自动合并到缺失；NA、NULL 等字面文本不自动当作空值。
- Quantity、Price 为数值统计对象。空字符串计缺失；非空但不能转换成有限数值的内容计转换失败，不能填 0。
- min/max/mean 基于有限有效数值；std 使用样本标准差 ddof=1。有效数少于 2 时 std 为 null，报告显示“不适用”。
- 其余字段统计非空唯一值及 TOP 10。排序按频次降序，并列按原始字符串 Unicode 升序；不裁剪空白、不改大小写。
- InvoiceDate 在原始字符串统计之外，按 YYYY-MM-DD HH:MM:SS 检查可解析性和范围，不推断时区。
- 异常标记仅用于探索，不代表应删除。Quantity 绝对值 ≥10000 是事先约定的查看阈值，不是业务有效性规则。
- 完全重复行按 8 个原始字段相等判断，计额外出现次数；不据此认定错误或直接去重。

## 验收门槛

| 编号 | 标准 | 如何验证 |
|---|---|---|
| Q11-A | 全量行数、字段、原始内容与锁定数据一致 | 输入哈希校验；执行前后原文件摘要一致 |
| Q11-B | 缺失率、数值统计、唯一值及 TOP 10 符合上述口径 | 可手算固定样本；不能调用生产函数生成预期 |
| Q11-C | 全量结果与独立计算一致 | pandas 生产实现对照 csv.reader + Decimal 独立流式计算，验证器不导入 Q1 生产统计函数 |
| Q11-D | 精度与守恒 | 计数/排序/最小最大值精确匹配；均值和 std 使用相对容差 1e-10、绝对容差 1e-8；缺失+有效+转换失败=总行数 |
| Q11-E | 至少 5 个不同的可疑现象有实际证据 | 报告写出计数、比例或极值以及下一步验证方向；观察与业务推断分开 |
| Q11-F | 测试能发现关键错误 | 漏计一行、ddof=0、丢失字符串空白、并列顺序错误、缺失率分母错误必须触发断言失败 |
| Q11-G | 可重复、可独立运行、无回归 | 独立入口及总入口生成相同 JSON/Markdown；骨架回归通过；未完成 Q1.2/Q1.3 继续标记未完成 |
| Q11-H | 证据对应本轮源码 | 保留失败及成功记录、数据摘要、源码摘要、手算依据和下一轮选择理由 |

计数/口径存在未解释差异时禁止进入 Q1.2。不得为通过测试修改原始数据或原数据基准。
验收报告只放行 Q1.1，不代表整个 Q1 完成。

## 后续方向的选择

先满足题目依赖：Q1.1 通过后进入 Q1.2，随后才形成 Q1.3 清洗策略并用于 Q3。
Q1.2 内优先核验会改变销售额或客户分群口径的异常；依据本轮真实数量、金额影响（待计算）及不确定性决定顺序。
不能仅按“容易做”选方向，也不能把尚未计算的金额影响写成既定事实。
