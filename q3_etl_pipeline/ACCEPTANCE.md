# Q3 修改前的口径与验收标准

目标：三份 Parquet、逐步日志、验证报告和独立/默认入口；本人先读懂旧代码不作为实施前提。

销售是正向商品毛交易：纯数字发票、正数量、正价，排除已知费用/调整/礼券/测试项；常规商品格式和经描述核对的特殊商品候选单列规则。原始记录不删、不默认去重，未知编码隔离并量化损失。ID 保留字符串，金额内部以千分单位整数计算，按题目要求导出 float。

RFM 按 sales_facts 的毛购买口径，有客户 ID 才参加；频次按不同发票，最近购买与原始数据最后一个自然日的天数差。国家按不同购买发票数最多、国家字典序打破并列。取消候选匹配不是确认退款，不能把毛购买特征称为净留存特征，必须披露潜在影响。

退货日志保留全部 C 前缀记录。只对负数量且有客户的记录尝试同客户、同原始商品码、相反数量的更早正向销售；最近时间优先、同时间按来源行倒序稳定选择并标记歧义。一笔销售行最多消费一次；部分退货不凑单、不猜分拆，找不到精确数量就 NULL 并记录原因。价格不同公开，不自动改价。匹配只是候选关系。

固定样本必须覆盖：同订单多商品、客户匿名、正单和退货同日、未来订单禁止、同时间/同价多候选、连续退货不得复用、买十退五精确数量不匹配、C 单正数量异常、非商品及有商品含义的特殊码、三位小数、RFM 国家并列。预先手算，不能用被测函数生成期望。

真实全量需独立 CSV/Decimal 复算销售行归属与金额、客户特征；匹配用独立逐候选检查验证最近/严格早于/容量及未匹配原因，不能只比总金额。三份文件回读校验字段、类型、行数、关键值，业务输出确定性重跑。百万行真实耗时须记录，目标低于 120 秒，未达到就说明失败，不伪报。

通过小样本后才扩大全量；只有正式入口与最新源码证据通过才标完成。人工业务确认和净退款真值尚未获得，不由程序断言替代。
